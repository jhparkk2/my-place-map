# 발자국 · 나만의 장소 지도

실제로 방문한 맛집·카페·명소를 지도에 기록하는 아이폰 친화형 웹앱입니다.

## 시작
GitHub Pages에서 배포: Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
이후 https://jhparkk2.github.io/my-place-map/ 에서 확인하세요.

## 발자국 v1.5 — 카카오맵 장소 검색 연결
- 카카오 JavaScript SDK의 장소 검색(Places.keywordSearch) 연결. **REST API 키를 공개하지 않음**
- 인천 옥련동 정동진횟집처럼 지역+상호 검색 후, 필요 시 상호명만 재검색
- 검색 결과의 상호·주소 확인 후 선택해 방문 기록에 저장
- 기존 파스텔 Leaflet 지도, IndexedDB 방문 기록·사진·후기·지역별 보기 유지
- 카카오 API가 로드되지 않으면 기존 주소 검색 제공자 보조 사용
- 카카오 개발자 콘솔에서 JavaScript SDK 도메인(https://jhparkk2.github.io) 및 카카오맵 API 사용 설정 필요
- 테스트 URL: https://jhparkk2.github.io/my-place-map/?v=15

## 발자국 v1.5 — 국내 식당 검색과 홈 검색 기능 개선
- 새 장소 등록에서 장소 검색창을 먼저 보여주고 보조 버튼은 접어두어 화면을 단순화
- 파스텔 지도(CARTO / OpenStreetMap)와 카테고리별 말풍선 마커, 사진이 들어간 지도 후기 카드
- **카카오맵 상호명 직접 검색 연동**: 앱의 '관리 > 카카오 장소 검색 연결'에서 JavaScript 키를 등록하면 '인천 옥련동 정동진횟집' 같은 검색을 카카오 장소 DB로 확인합니다.
- 카카오 개발자 페이지에서 지도 API를 활성화하고 JavaScript 키의 SDK 허용 도메인에 https://jhparkk2.github.io 를 등록하세요. 도메인 경로 `/my-place-map/`는 입력하지 않습니다.
- REST API 키를 HTML 파일이나 공개 GitHub 저장소에 절대 넣지 마세요. 이 버전은 JavaScript 키만 브라우저 저장소에 보관합니다.
- 첫 화면 바로 검색 기능을 추가했습니다. 카카오 검색에 실패하거나 키가 없다면 기존의 해외 지도 검색과 지도 직접 지정으로 전환합니다.
- 기존 사용자 사진·방문 기록은 같은 브라우저 IndexedDB에 유지됩니다.

## 제공 기능
- 지도에서 장소 확인 (OpenStreetMap / Leaflet)
- 장소 주소 검색 (OpenStreetMap Nominatim)
- 방문 후기, 사진 최대 3장, 별점, 재방문 표시
- 카테고리별 기록 보기
- **지역별 보기**: 시·도 → 동/읍/면 → 방문 장소로 탐색 (기존 방문 기록도 주소로 가능한 범위에서 자동 분류)
- 등록/수정 시 시·도와 동네를 선택하거나 직접 수정 가능
- 국내 상호명 검색 보강, 카카오맵 검색 연결, 지도에서 직접 위치 지정
- 내 기록(JSON) 내보내기/복원
- 아이폰 Safari에서 홈 화면에 추가 (PWA)

## 꼭 알아둘 점
현재 v1은 시험용 개인 앱입니다. 로그인이나 서버 동기화가 없고 저장된 장소와 사진은 해당 브라우저의 IndexedDB에 남습니다. 기기를 바꾸거나 데이터를 삭제하기 전에 '내 기록 관리'에서 백업을 내려받으세요. 공유 기능은 장소와 후기 텍스트를 공유합니다. 온라인 지도와 장소 검색은 인터넷이 필요하며 OSM/Nominatim 사용 정책을 따라야 합니다. 공개 서비스를 출시하기 전에는 서버 저장, 개인정보 보호, 지도 서비스 운영 정책과 검색량 제한을 검토해야 합니다.
