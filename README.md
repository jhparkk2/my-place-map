# 나와봄 · 내가 와본 곳, 오래 남을 기억.

**나와봄**은 직접 방문한 맛집·카페·명소를 사진과 후기로 담고, 지도에서 다시 찾아보거나 친구·가족에게 공유하는 아이폰 친화형 웹앱입니다.

## 앱 실행
- 앱 주소: https://jhparkk2.github.io/my-place-map/
- GitHub Pages 배포: Settings → Pages → Build and deployment → Deploy from a branch → main / (root)
- 아이폰에서는 Safari로 접속해 '홈 화면에 추가'하여 앱처럼 사용할 수 있습니다.

## 현재 제공 기능
- 카카오맵 장소 검색과 위치 지정
- 지도에서 방문한 장소 보기, 카테고리별·지역별 탐색
- 방문일, 후기, 별점, 사진, 재방문 기록
- 장소 상세 화면과 공유 링크
- 내 기록 JSON 백업 및 불러오기

## 앱 이름 변경
- 이전 이름: 발자국
- 새 이름: **나와봄**
- 앱 화면, 브라우저 제목, 아이폰 홈 화면용 이름, 공유 문구에 새 이름이 적용되어 있습니다.
- 기존의 저장 데이터 식별자와 백업 형식은 변경하지 않아 이전 기록과 백업 파일을 계속 사용할 수 있습니다.
- GitHub 저장소 및 앱 주소 `my-place-map`은 기존 공유 링크가 끊어지지 않도록 그대로 유지합니다.

## 이용 시 주의
기록·사진 저장과 공유 방식은 기능 및 설정에 따라 다를 수 있습니다. 중요한 기록은 반드시 앱의 '내 기록 백업' 기능으로 백업한 뒤 업데이트하거나 홈 화면 앱을 다시 설치하세요. 지도와 장소 검색은 인터넷 연결이 필요합니다.

## v3.0 공유 UX 개선 (2026-10-16)
- 장소 상세 페이지의 **사진·후기 카드 공유** 버튼을 한 번 누르면 iOS의 공유 메뉴로 직접 진입합니다.
- 사진, 장소 이름, 주소, 별점, 방문일, 후기 요약을 한 장의 JPG 카드 이미지로 합칩니다.
- 기존 복잡한 공유 선택 화면은 일반 앱 사용 흐름에서는 열리지 않습니다. 기존에 전송한 공유 링크가 계속 열리도록 관련 수신 기능은 보존합니다.
- 카카오 JavaScript SDK 의존성은 제거했습니다. 기존 내 장소 기록/사진 저장소 구조는 그대로 유지합니다.
- 카드 이미지는 클릭 가능한 장소 링크가 아닙니다. iOS Safari의 실제 공유 동작은 실기기에서 확인해야 합니다.

## v3.1 클릭 가능한 카카오톡 카드 (2026-10-16)
- 장소 상세 → **공유하기** → **연결 카드 준비하기** → **카카오톡으로 연결 카드 보내기**
- 본인이 버튼을 누른 때에만 공개 Supabase 저장소에 선택한 사진 1장과 장소 요약을 업로드합니다.
- Kakao Share feed 템플릿의 카드 이미지와 하단 버튼에 같은 `#cloud=` 장소 링크를 지정해 수신자가 해당 나와봄 장소를 열도록 구성합니다.
- JavaScript SDK는 필요 시 2.8.3 공식 CDN에서 불러옵니다. 앱의 JavaScript 키로 초기화합니다.
- 카카오 개발자 앱의 **JavaScript SDK 도메인**과 **제품 링크 관리 > 웹 도메인** 양쪽에 `https://jhparkk2.github.io` 등록 필요.
- SDK 로딩, 키, 개발자 설정 문제가 있거나 미작동하면 오류 안내를 표시하고 기존 **사진만 보내기** 방식을 유지합니다.
- 앱의 IndexedDB 스키마/기존 기록/기존 공개 링크 URL 구조를 수정하지 않습니다.
- 실제 카카오톡 연결 카드 전송과 누르기 동작은 아이폰에서 검증해야 합니다.


## v3.2 공유 간소화 (2026-10-17)
- 장소 상세의 "공유하기"에서 사진/장소 정보를 미리 확인합니다.
- 주된 버튼은 "장소 링크 준비하기" → "카카오톡에 장소 보내기" 순서입니다. 처음 사진 링크 준비는 공개 Supabase 스토리지 업로드에 사용자 동의가 필요하므로 분리되어 있습니다.
- 카카오 SDK를 사용할 수 없는 경우 주된 버튼이 "장소 링크 공유하기"로 바뀌며, 아이폰 기본 공유 메뉴에서 사진·후기가 열리는 URL을 보냅니다. 일반 URL 미리보기는 앱 로고일 수 있지만 링크를 누르면 공유한 장소가 열립니다.
- 작은 "링크만 복사하기" 버튼을 추가하고, 사진만 공유하기는 접힌 도움말로 옮겼습니다.
- 카카오 사진형 피드 카드 자체를 보내려면 앱 JavaScript SDK 도메인 및 제품 링크 웹 도메인 두 설정에 \`https://jhparkk2.github.io\` 등록이 필요합니다. 이 설정은 웹앱 코드만으로 바꿀 수 없습니다.
- IndexedDB의 장소·사진·백업 포맷과 과거 공유 링크는 변경하지 않았습니다.
- 아이폰 실기기 및 카카오톡 전송/연결 테스트는 아직 필요합니다.

## v3.6 최근 카드 크기 통일 (2026-10-17)
- 최근 기록 카드 크기를 작은 높이 306px로 고정하고, 모든 이미지와 사진 없는 자리도 동일한 156px 영역으로 통일합니다.
- 가로/세로 사진 모두 `object-fit:contain`으로 보여줘 사진 원본이 잘리는 것을 방지합니다. 세로 사진은 좌우 여백이 생길 수 있습니다.
- v3.5의 사진 자체 높이(`height:auto`) 때문에 카드 크기가 달라지던 문제를 수정했습니다.
- 저장된 사진·방문 기록·지도·검색·공유는 변경하지 않았습니다.

## v3.7 최근 사진 여백 개선 (2026-10-17)
- 최근 카드의 크기(높이 306px)와 사진 영역(156px)은 유지합니다.
- 세로 사진의 좌우 빈 부분은 같은 사진을 배경에 흐리게 확대하여 채웁니다. 가운데에는 원본 사진을 그대로 보여주므로 잘리지 않습니다.
- DOM 이미지 요소를 복제해 배경 레이어로 사용하며 개인 기록이나 사진 파일을 수정하지 않습니다.
- 지도, 장소 등록, 공유 흐름, IndexedDB 저장 및 백업 형식은 그대로 유지합니다.

## v3.9 현재 위치 지도 표시 (2026-10-19)
- 메인 화면의 ‘나만의 장소 지도’ 오른쪽 상단에 ‘⌖ 내 위치’ 버튼 추가

- GPS 권한 거절, 시간 초과, 위치 측정 불가 상황에 상태 안내 제공
- 아이폰 Safari 또는 홈 화면에 추가한 앱에서 실제 위치 권한과 좌표 정확도 테스트 필요

- 긴 공백 없는 문장/URL이나 긴 장소 이름도 가로 화면 확장을 일으키지 않도록 카드 내부 최소 크기와 줄바꿈을 보완했습니다.
- 기존 카드 형태·사진 크기·좋아요 버튼·상단 메뉴와 방문 기록/사진/저장 데이터 구조는 유지합니다.
- 아이폰 Safari에서 `?v=420`으로 접속해 긴 후기가 있는 내 기록 목록에서 화면을 좌우로 밀었을 때 전체 페이지가 이동하지 않는지 확인하세요.
