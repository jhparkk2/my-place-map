보낼 내용 미리보기

📷 사진이 열리는 장소 링크카카오톡에는 짧은 링크 하나만 보내요. 받는 사람이 누르면 실제 방문 사진·별점·후기를 한 화면에서 볼 수 있어요.

아이폰 공유 메뉴에서 카카오톡을 선택하세요. 사진 파일을 직접 보내는 방식이라 장소 링크가 함께 전달되지 않을 수 있어요.

사진 카드 공유는 카카오 개발자 도메인 설정이 필요합니다. 사진 직접 공유는 설정 없이 사용할 수 있어요.

사진을 바로 보낼 때는 위쪽 「내 사진 바로 공유」를 누르세요. 장소 사진이 포함된 클릭 가능한 카드 공유는 링크 준비와 카카오 개발자 설정이 필요해요.

🔒 링크를 준비하면 선택한 사진 한 장과 장소 정보가 공개용 저장소에 올라갑니다. 링크를 아는 누구나 볼 수 있고 다른 사람에게 전달할 수 있어요. 공유 취소·친구만 보기·댓글 동기화는 아직 지원되지 않습니다. 사진 직접 공유는 온라인 업로드 없이 아이폰 공유 메뉴로 전송하며, 카카오톡 카드 공유는 사진과 장소 제목을 카드에 넣는 별도 방식입니다. 일반 링크 붙여넣기는 나와봄 대표 이미지로 표시되며, 기존 카카오톡의 미리보기 캐시가 남을 수 있어요.
